Voyager-2 Spacecraft Bus Orientation C-kernel, with made-up AVs
===========================================================================

     This CK file contains the same attitude data as the vgr2_super.bc
     CK file but this attitude is accompanied by made-up angular
     velocities that represent constant rate rotations from each
     attitude point to the next attitude point.
 
     This file was made by dumping SCLK-tagged attitude from
     vgr2_super.bc into chunks corresponding to each of the source CK
     segments, re-packaging those attitude chunks back into individual
     single segment CK files with made-up angular velocities using the
     MSOPCK setup shown below, and merging individual CKs files
     together to make this file using DAFCAT.

     The following MSOPCK setup file was for re-packaging:

        \begindata
           LSK_FILE_NAME           = 'naif0011.tls'
           SCLK_FILE_NAME          = 'vg200022.tsc'
           FRAMES_FILE_NAME        = 'vg2_v02.tf'
           INTERNAL_FILE_NAME      = 'vgr2_super_v2.bc'
           CK_TYPE                 = 3
           CK_SEGMENT_ID           = 'vgr2_super.bc repackaged with AVs'
           INSTRUMENT_ID           = -32000
           REFERENCE_FRAME_NAME    = 'ECLIPB1950'
           ANGULAR_RATE_PRESENT    = 'MAKE UP/NO AVERAGING'
           INPUT_TIME_TYPE         = 'SCLK'
           INPUT_DATA_TYPE         = 'SPICE QUATERNIONS'
           PRODUCER_ID             = 'BVS/NAIF'
        \begintext

     The comments from the original CK are below.

     BVS/NAIF, November 17, 2015.



Voyager-2 Spacecraft Bus Orientation C-kernel
===========================================================================
 
Introduction.
--------------------------------------------------------
 
     This type-3 C-kernel contains data that describes the orientation of the
     Voyager-2 spacecraft bus relative to the 'ECLIPB1950' inertial frame.
 
     The NAIF ID of the Voyager-2 spacecraft is -32.
 
     The NAIF ID of the Voyager-2 spacecraft bus reference
     frame is -32000.
 
     Angular velocities are NOT present in this file.
 
     Beginning 1989-OCT-02, the spacecraft's orientation is described
     with predicted values.
 
 
Time Coverage
--------------------------------------------------------
 
     Start time =  1977-AUG-20 16:06:18.353 (UTC)
     End time   =  2027-DEC-27 00:00:00.005 (UTC)
 
     Gaps in coverage are listed below in section
     "Segment List and Gap Interpolation".
 
 
Source and Disclaimer
--------------------------------------------------------
 
     Sandy Kramer of NASA/GSFC provided NAIF with Voyager Project
     fixed instrument Supplemental Experiment Data Records (SEDRs).
 
     The suppliers of the input data files stated that
     they make no guarantee on the data or conversion programs.
     Some of the original data may have been corrupted as a result of
     degradation of the original storage tapes before archiving on CDROM.
 
 
Processing
--------------------------------------------------------
 
     1. The SEDR files provided by GSFC were originally stored on IBM System 370
        9-track tapes.  Sandy Kramer copied the data to a VAX/VMS system.
        These files were transferred by ftp to NAIF's VAX.
 
     2. The "SEDRBLOCK" program converted the IBM files
        to their original record structure.
 
     3. "SEDRCNVT" converted the data's IBM binary representation
        to VMS.
 
     4. The program "SEDR_VIEW" created text files of spacecraft
        orientation.
 
     5. The program "VOYATT2" read the orientation text files
        and output a C-kernel file.
 
 
Checks and Accuracy of the Data
--------------------------------------------------------
 
     The "CKDUMP" program performed the following data checks:
 
     (1) Earth pointing check.  For most of the mission, the boresight
         of the High Gain Antenna (HGA) pointed towards Earth.
         For each input spacecraft attitude matrix, the angle between
         the HGA and Earth was determined.  No corrections were
         made for aberration or light time.  Below is a histogram
         of Earth-boresight angle:

     (2) Lockstar in star tracker field of view check.  The
         Voyager star tracker is modeled as a rectangular

         Lockstar outside of tracker FOV =   31992 instances
 
 
Segment List and Gap Interpolation.
--------------------------------------------------------
 
     The input files used to create this C-kernel are listed below,
     along with some information about the data in the file.
 
 
     Each input file resulted in a separate C-kernel segment.
 
 
     Gaps between segments were bridged where possible by tacking on
     the first point of the following segment.
 
 
     Two criteria had to be satisfied before spanning an inter-segment gap:
 
 
     Gap width:  The gap width must be less than 2.5 times the
                 average distance between points in the
                 preceding file.
 
     Quaternion difference norm (QDN):  Each C-matrix in the input
                 file was converted to a quaternion (a 4-vector) and
                 the average norm of the difference between consecutive
                 quaternions was calculated.  The standard deviation of
                 the QDNs was also determined for each input file.
 
                 If the QDN across the gap was less than the average
                 QDN plus 1.5 times the QDN standard deviation,
                 and the if gap width criteria above was also satisfied,
                 the gap was spanned.

                  spanned, then '||' symbols are shown.

Usage
--------------------------------------------------------
 
     The NAIF SPICE toolkit routines CKGP and PXFORM can
     be used to obtain linearly interpolated C-matrices
     from the data in this file.  The user must provide their
     own routines to interpolate across gaps.
 
     A Voyager-2 spacecraft clock kernel covering the
     time range depicted in this file is available.
 
     Instructions for loading and using of C kernels are
     found in the NAIF documents, "CK Required Reading" and
     "Frames."
