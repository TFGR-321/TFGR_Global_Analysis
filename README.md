# TFGR_Global_Analysis
TFGR models a scale-dependent temporal field with Δt(L)=Δt₀(1+(L/Lc)^p)^q, where Lc≈4×10⁹ m. This single relation explains atomic-clock shifts, GPS/LLR anomalies, deep-space probe residuals, galaxy rotation curves, lensing signals, and late-time cosmic acceleration, with reproducible code and datasets provided.
